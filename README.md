# Nieto Web Studios

Landing page de mi marca personal: páginas web, cartas digitales con QR y soluciones a medida para restaurantes, cafeterías, tiendas y pequeños negocios.

Todo está en un solo archivo, `index.html` (HTML, CSS y JavaScript, sin frameworks ni compilación). Para verla, abre el archivo en el navegador.

## Editar

- **WhatsApp:** el número está en `WA_NUMBER`, dentro del script al final de `index.html`. Cada botón tiene su propio mensaje en el atributo `data-wa="..."`.
- **Colores y tipografías:** en las variables de `:root`, al inicio del `<style>`.
- **Animación de la portada:** los negocios de ejemplo están en `SETS`, dentro del script.

## Proyectos

- [ISQAY](https://alitas-isqay.netlify.app/): página de demostración para un restaurante de alitas a la brasa.
